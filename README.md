# SRTA Transplant Tracker

Weekly dashboard for Strata Critical Medical (Nasdaq: SRTA): U.S. transplant volumes by organ, donor mix, how far organs travel, where transplants happen, and industry news. Static GitHub Pages site; every number on the page is read from a JSON file in `data/` that names its source.

## Data tags

| Tag | Meaning |
|---|---|
| **Live** | Fetched automatically by the weekly GitHub Action (price, news) |
| **Manual** | Parsed from an OPTN export file dropped into `data/raw/optn/` |
| **Linked** | External tool linked, not copied (organ-miles tracker) |

## Layout

```
config/keywords.json         news keyword groups, filters, digest headline ranking (edit freely)
config/signals.json          thresholds for the "What the data says" strip
config/health.json           staleness limits for the data-issue banner
config/holdings.json         JOBY share count used for the contingent-consideration value (manual, sourced)
config/optn_regions.json     OPTN region -> states (copied from hrsa.gov region pages)
data/raw/optn/               OPTN weekly downloads (dated); national/ = monthly snapshots
data/manual/                 company_kpis.json, tmdx_kpis.json: quarterly KPIs you fill in (source + date per field)
data/processed/*.json        what the site reads (regenerated by scripts; never hand-edit)
data/weekly_summary.json     structured weekly digest + "This week" bullets + signals
summary/latest.md            <=10-line Slack-ready digest (posting not built)
scripts/fetch_price.py       SRTA, TMDX, JOBY closes (Yahoo chart API, no key)
scripts/fetch_news.py        Google News RSS + publisher-URL resolution + filters
scripts/fetch_optn.py        OPTN metrics dashboard (Playwright): transplants, donors, waitlist, regions
scripts/fetch_optn_national.py  OPTN national data + advanced reports (plain HTTP): DCD, distance, state, centers
scripts/fetch_cdc.py         CDC/NCHS overdose deaths (data.cdc.gov xkb8-kh2a, no key)
scripts/fetch_sec.py         SRTA filings from SEC EDGAR (needs SEC_USER_AGENT secret with a contact email)
scripts/ingest_optn.py / ingest_national.py   raw OPTN files -> processed JSON
scripts/health.py            fetch failures + staleness -> data/processed/health.json (banner + "Data issue:" line)
scripts/build_digest.py      weekly_summary.json + summary/latest.md
tests/                       unit tests (week/YoY math, signal labels, news filters)
```

**Setup:** add a repository secret `SEC_USER_AGENT` (Settings → Secrets → Actions), e.g. `srta-transplant-tracker you@example.com`. SEC rejects requests without a contact email; the email is kept out of this public repo.

## Weekly workflow

`.github/workflows/weekly-update.yml` runs Sunday 23:00 UTC, on pushes touching `data/raw/optn/` or `data/manual/`, and on demand. Every fetch may fail without stopping the run; `health.py` turns failures and stale data into a page banner and a "Data issue:" line, and the run is marked red after the commit.

Run locally:

```bash
python3 scripts/fetch_price.py; python3 scripts/fetch_news.py; python3 scripts/fetch_optn.py; python3 scripts/fetch_optn_national.py; python3 scripts/fetch_cdc.py; SEC_USER_AGENT="name you@example.com" python3 scripts/fetch_sec.py; python3 scripts/ingest_optn.py; python3 scripts/health.py; python3 scripts/build_digest.py
```

## Rules the code enforces

- **Incomplete weeks are dropped.** A week is kept only if it ended before the file's download date (from the filename prefix).
- **Year-over-year by default.** OPTN week N (week 1 starts Jan 1; week 52 runs to Dec 31) is compared with week N of the prior year; trailing-4-week and YTD compare the same week spans. If any prior-year week is missing, the YoY shows `n/a` instead of a partial comparison. OPTN's own "(Partial Week)" rows are dropped.
- **Annual-only national data is never compared as volumes.** Donor mix, distance and state tables compare shares (current YTD vs prior full year, labelled as a mix comparison). State % change appears only once a monthly snapshot for the same period end a year earlier exists.
- **No placeholders.** A panel with no parsed data shows "Awaiting data".
- **No sell-side research in the repo.** No reports, models, charts or text from brokers. The news feed carries headlines only (with links), filtered by `config/keywords.json`: junk aggregators and consensus-estimate spam are always dropped; analyst rating / price-target headlines are kept only when they name SRTA or TMDX, and are tagged "Analyst actions".

## Processed files (OPTN)

| File | Source | Shape |
|---|---|---|
| `transplants_weekly.json` | OPTN metrics dashboard (weekly) | `organs: {heart\|liver\|lung\|kidney\|all: [{yr, week, week_start, week_end, count}]}` |
| `donors_weekly.json` | OPTN metrics dashboard (weekly) | `donors: [...]` (same row shape), `ytd_table: [{yr, ytd_deceased_donors, discard_rate_pct, ...}]` |
| `regions_weekly.json` | OPTN metrics dashboard (weekly) | `regions: {"1".."11": [rows]}`, `region_states` |
| `donor_mix.json` | OPTN national data (monthly) | `donors` / `transplants_by_organ[organ]`: `{year: {dbd, dcd, total, dcd_share_pct}}` |
| `distance.json` | OPTN national data (monthly) | `organs[organ][year]: {bands, shares_pct, long_share_pct}` |
| `centers.json` | OPTN advanced report (monthly) | `rows: [{center, center_code, organs, total_<year>, yoy_pct, total_ytd}]` (top 25) |
| `waitlist_weekly.json` | OPTN metrics dashboard (weekly) | `organs: {organ: [rows]}` (kidney incl. kidney-pancreas) |
| `cdc_overdose.json` | CDC/NCHS (monthly) | `series: [{period_end, reported, predicted, *_yoy_pct}]` |
| `sec_filings.json` | SEC EDGAR (weekly) | `filings: [{form, filed, description, url, form4?}]` |
| `price.json` | Yahoo (weekly) | `tickers: {SRTA\|TMDX\|JOBY: {history}}` |
| `health.json` | health.py | `issues`, `notices` |
| `location.json` | OPTN national data (monthly) | `rows: [{state, ytd, share_pct, prior_full_year, prior_share_pct, yoy_pct?}]`, `snapshots` |

Each carries `source`, `tag`, `status` (`ok` / `awaiting_data`), `raw_file`, `data_as_of`. Note: the metrics dashboard's "Kidney" includes kidney-pancreas; the national data's kidney is kidney alone.
