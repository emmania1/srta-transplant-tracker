# SRTA Transplant Tracker

Weekly dashboard for Strata Critical Medical (Nasdaq: SRTA): U.S. transplant volumes by organ, donor mix, how far organs travel, where transplants happen, and industry news. Static GitHub Pages site; every number on the page is read from a JSON file in `data/` that names its source.

## Data tags

| Tag | Meaning |
|---|---|
| **Live** | Fetched automatically by the weekly GitHub Action (price, news) |
| **Manual** | Parsed from an OPTN export file dropped into `data/raw/optn/` |
| **Linked** | External tool linked, not copied (organ-miles tracker) |

## Layout

```
config/keywords.json         news keyword groups + source/headline filters (edit freely)
data/raw/optn/               drop OPTN exports here, named YYYY-MM-DD_<description>.<ext>
data/processed/*.json        what the site reads (never hand-edit; regenerated by scripts)
data/weekly_summary.json     structured weekly digest + the page's "This week" bullets
summary/latest.md            <=10-line Slack-ready digest
scripts/fetch_price.py       SRTA closes from Yahoo Finance chart API (no key); keeps last good value on failure
scripts/fetch_news.py        Google News RSS, one query per keyword group; dedupe by URL + near-identical headline; 90 days
scripts/ingest_optn.py       OPTN raw files -> processed JSON (parsers pending real sample exports)
scripts/metrics.py           incomplete-week filter + YoY math (shared)
scripts/build_digest.py      weekly_summary.json + summary/latest.md
tests/test_metrics.py        unit tests for the week/YoY math
```

## Weekly workflow

`.github/workflows/weekly-update.yml` runs Sunday 23:00 UTC, on any push that touches `data/raw/optn/`, and on demand (`workflow_dispatch`). It tests, fetches price + news, re-ingests OPTN files, rebuilds the digest, and commits.

Run locally:

```bash
python3 scripts/fetch_price.py && python3 scripts/fetch_news.py && python3 scripts/ingest_optn.py && python3 scripts/build_digest.py
```

## Rules the code enforces

- **Incomplete weeks are dropped.** A week is kept only if it ended before the file's download date (from the filename prefix).
- **Year-over-year by default.** Week N is compared with ISO week N of the prior year; trailing-4-week and YTD compare the same ISO-week spans. If any prior-year week is missing, the YoY shows `n/a` instead of a partial comparison.
- **No placeholders.** A panel with no parsed data shows "Awaiting data".
- **No sell-side material.** News filters drop rating/target/estimate headlines and aggregator sources (see `config/keywords.json`).

## Normalized processed schemas (OPTN)

Parsers write these shapes; the page and digest read only these.

- `transplants_weekly.json`: `organs: {heart|liver|lung|kidney: [{week_start, week_end, count}]}`
- `donor_mix.json`: `donors: [{period, dbd, dcd}]`, `dcd_share_by_organ: {organ: [{period, dcd, total}]}`
- `distance.json`: `band_order: [...]`, `long_bands: [...]`, `organs: {organ: [{period, prior_year_period, bands: {band: count}}]}`
- `location.json`: `level: "state"|"region"`, `latest_period`, `prior_period`, `rows: [{area, latest, prior}]`

Each also carries `source`, `tag`, `status` (`ok` / `awaiting_data`), `raw_file`, `data_as_of`.
